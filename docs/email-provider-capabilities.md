# Email implementation and qualification matrix

Snapshot: 1 November 2026. This is a development checkpoint, not a production support promise. The combined local candidate follows `70bc46b19a8896104eccdc3d944cf4352f849224` with the private-intake qualification work recorded here. See the [current validation record](mail-candidate-validation-status.md) for exact evidence and open gates. Preserve installed migration history and check the actual candidate before deployment.

## Evidence levels

- Source: implementation exists and is reviewable.
- Automated: the named unit, real PostgreSQL or native TLS fixtures passed. A fixture does not establish compatibility with an arbitrary provider.
- Controlled server: the isolated GreenMail 2.1.15 workflow was exercised. It does not establish external-account operation.
- External provider: the exact provider, account type, capabilities and authorized real-account workflow were qualified. No new external-provider acceptance is claimed here.
