# Recorded deal source performance

This read uses current live deal records and the existing fixed CRM source-channel taxonomy. It shows separate deal creation, current won and current lost counts in the viewer’s civil period; a deal may contribute to creation and outcome counts. Exact known won value in the selected currency is accompanied by the value sample count. A true zero remains a known value. Win-cycle totals use exact microseconds and include only wins with a nonnegative interval from recorded creation. These are current deal outcomes and nominal deal values, not lead conversion, sourced revenue or campaign attribution.

The reader resolves current actor, owner, pipeline, currency and effective account/device zone in one bounded read-only repeatable-read transaction. Unknown free text and absent input enter distinct fixed categories. It never returns raw channel strings outside the registry, campaign references or deal records. A scope above 200,000 eligible deals is unavailable rather than truncated. The prepared native fixture covers exact money and elapsed time, missing values, legacy unknown sources, civil-date edges, inaccessible pipeline, other-owner, archived and mixed-currency deals, and a deactivated viewer. Hosted native execution and viewer wiring remain pending.
