## Time to first close

`dealCloseIncidence.ts` computes a descriptive Aalen–Johansen baseline for observed entrants. Won and lost are competing first close outcomes; deals still open at the common observation cutoff are right-censored. Each tied age uses the risk set before withdrawing outcomes or censors. Exact integer arithmetic preserves mass before presentation, and the output ends at the last observed age. An empty, all-censored or observed-no-win population is distinct. The caller must establish a complete authorized roster, observed insert and first transaction-final close or open observation, and a common cutoff. A source assertion is not proof of those facts.

The ten focused fixtures include hand calculations, tied outcomes and censoring, exact nanosecond ages, bounded and incomplete inputs, and rounding that conserves mass. Still required: a qualified native roster, reference comparison against the [R survival multistate estimator](https://cran.r-project.org/web/packages/survival/refman/survival.html), interval and temporal evaluation, and a separate permission and disclosure policy. Precise age steps stay internal. The baseline assumes censoring is not informative within the analysis population; it supplies neither a calibrated prediction nor a causal result.

## MMM

A candidate engine is a pinned [Google Meridian](https://github.com/google/meridian) release. Its [input contract](https://developers.google.com/meridian/reference/api/meridian/data/input_data/InputData) needs an aligned geo × regular-time panel: summable KPI, consistent currency/unit, population, channel exposure/spend, justified controls, lag history, explicit missingness and source revisions. Missing earlier media history must not silently become genuine zero exposure. [Preparation](https://developers.google.com/meridian/docs/pre-modeling/collect-data) and [data sufficiency guidance](https://developers.google.com/meridian/docs/pre-modeling/amount-data-needed?hl=en) are suitability prerequisites, not automatic acceptance thresholds.

Current installation documentation, README and floating package metadata disagree on Python support. Resolve compatibility against the exact selected package rather than floating `main`; retain the actual dependency/runtime manifest and reference-case results. [Installation](https://developers.google.com/meridian/docs/user-guide/installing), [package metadata](https://raw.githubusercontent.com/google/meridian/main/pyproject.toml).

Freeze preprocessing, priors, source revisions and evaluation choices before examining held-out outcomes. Predictive holdout performance does not establish causal identification. Control selection must handle confounders without treating mediators as controls; convergence alone does not establish causality. Preserve holdout/adstock semantics, diagnostics and uncertainty. [Model configuration](https://developers.google.com/meridian/docs/user-guide/configure-model), [causal graph](https://developers.google.com/meridian/docs/causal-inference/causal-graph), [health checks](https://developers.google.com/meridian/docs/post-modeling/health-checks).

## Randomized paired geo

[Google Trimmed Match](https://github.com/google/trimmed_match) is the candidate reference for the retained paired-geo scope. Its package has a native C++ core/Python wrapper and Bazel build; compatibility and numerical parity require actual qualification. Preserve pretest/posttest outcome/spend, immutable geo pairs, randomized assignments, dates, exclusions/contamination and prespecified confidence/power/matching evidence. Pairing cannot use evaluation-period outcomes. Zero or near-zero spend contrast is invalid/insufficient evidence, never a genuine zero iROAS result. [Design guide](https://github.com/google/trimmed_match/blob/master/trimmed_match/g3doc/Trimmed_Match_design_colab_guide.md), [estimator source](https://raw.githubusercontent.com/google/trimmed_match/master/trimmed_match/estimator.py).

[Meridian GeoX](https://developers.google.com/meridian/geox) is an additional candidate with other designs. It does not silently replace paired-geo acceptance.
