# Source admission, attribution and scenario calculations

These private calculations support the source, attribution and forecast work in I3. Each requires an authorized input collector and a separate report projection. They do not call a provider, write data, assume Goals ownership or qualify a model.

The source admission planner receives a parsed batch and bounded prior receipts. A versioned digest preserves each original payload's scalar values, including timestamp and money spelling. It distinguishes exact retry, reused key and changed payload. Consecutive corrections must name the current event of the same producer, record and family. Any conflict rejects the entire plan. The future writer must prove its receipt set complete, authenticate the producer and recheck keys and correction tips in the transaction that persists the batch.

The attribution kernel compares first touch, last touch, linear and discrete half-life credit for one deduplicated qualified purchase or win. It requires explicit person or account identity and complete source coverage of the half-open interval ending at the conversion. Equal instants use stable interaction identifiers as a reproducible tie break, with no claim that their order is known. Each complete elapsed half-life halves the weight. Largest-remainder allocation conserves one million credit parts per model. Direct, unknown, uncaptured and no observed touch remain distinct. The source cut, identity definition and contributing revisions make the result reproducible. Descriptive credit does not measure incremental lift. A collector must resolve links, deduplicate conversions and apply corrections and permissions before calculation.

The forecast kernel evaluates conservative, base and upside assumptions over one open-deal population and one currency. Each expected count uses an explicit win probability times an explicit probability of closing during the selected target, conditional on that win. Value also needs a recorded amount; a supplied versioned size factor is optional. Exact products are summed before display rounding. Zero and missing remain separate, and a recorded expected date never supplies a probability. The collector must prove complete current membership and that factors use the same win definition, target and cutoff. These scenarios are what-if arithmetic. They supply no fitted probability, interval, target ownership or calibration evidence.

Focused cases cover exact retry and conflicting revisions, correction ordering and completeness; attribution boundaries, equal timestamps, source corrections and conservation; and scenario precision, bounded membership, timezone/target compatibility, future evidence and known versus missing inputs. These cases do not qualify real source data, durable snapshots, disclosure or installed reporting.
