# Hosted analytics browser qualification

The analytics pack uses the existing hosted full-browser job's production app build, native password sign-in, loopback proxy and disposable PostgreSQL. Its additional synthetic fixtures are seeded only after the existing serial packs finish. Both seed and browser entry points use the existing environment admission guard. No local browser, database or app build is authorized by this pack.

The prepared journey checks four dashboard/contributing-deal populations, exact values (including zero and missing), owner and currency scope, an actor-owned restricted-pipeline sentinel in the all-pipelines view, keyboard drawer dismissal/focus restoration, and a deal opening in a separate tab. A persisted UTC versus Los Angeles time-zone change tests the same civil day across a 00:30Z win. Gregorian/Persian month, quarter, year and last-30 presets are checked across language/calendar combinations.

The pack is designed to retain a structured receipt and paired dashboard/drawer images for 12 EN/DE/FA × light/dark × desktop/mobile Chromium contexts. It checks language, text direction, theme, drawer side and viewport fit. The workflow always attempts to upload the scoped analytics evidence directory. Browser contexts close after each journey; the pool, browser and in-memory session are cleaned up at the end. No traces, request bodies, headers, cookies, sign-in screenshots or storage state are intentionally retained.

At this source cut, Node syntax and eight focused workflow/environment contracts passed. Initial formatter diagnostics for a cleanup throw, comma expression and DOM text reads were corrected. Independent source review confirmed seed isolation, the restricted-pipeline negative control and preservation of the original failure through context cleanup. Hosted selectors, native runtime and rendered review remain unexecuted at this source cut. This suite provides synthetic backend/browser evidence when it runs; it does not establish history migration, human accessibility, provider, production installation or release acceptance.
