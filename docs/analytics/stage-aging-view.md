# Current cohort stage aging: private viewer adapter

The stage-aging adapter describes the captured stays of currently live, authorized deals in one currency, pipeline selection and effective owner scope. It does not describe a historical dashboard date range. It keeps completed durations, current open ages and lower bounds for unknown entries separate. The baseline is not a fabricated start date. Current labels come from the same repeatable-read observation as the statistics; the report does not present historical stage names.

The bounded collector validates active capture, live tips, every raw stage/pipeline reference and both captured deal sides against the request actor’s current grants. A currently visible deal does not confer access to its previously private states. A single denied side or incomplete source withholds the full report. On the viewer boundary, report-dependent failures collapse to a generic unavailable state with no counts. The projection returns only authorized labels, aggregate measures, selected currency and coverage times. It supplies no record or linked-contact IDs, contributors, native snapshots, internal errors or historical owner labels. Exact aggregates are about the authorized cohort, and a small sample is not anonymous.

Focused stage statistics and projection checks passed 54 cases. The prepared native tests verify current labels after rename, a restricted prior pipeline, and a same-pipeline private owner transfer. The latter cases require hosted execution against disposable native PostgreSQL. No viewer route, browser acceptance, installed capture or canonical migration is claimed by this adapter.
