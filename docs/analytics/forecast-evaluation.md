# Private saved forecast evaluation baseline

`forecastEvaluation.ts` is a private source kernel beside `periodForecast.ts`. It supports a bounded part of forecast accuracy under #600 and the #8 specification extension pending registration. It reuses PeriodForecast version and scenario identifiers plus existing currency and timezone validators. The original expected-won-value contribution is retained at up to 22 decimal places. A saved probability is the exact in-period joint probability from the original scenario, not the marginal eventual-win probability.

Each period pairs one complete original forecast manifest with an independently complete settled actual manifest referencing that forecast and the exact saved open-deal roster. The prediction cutoff and immutable saved receipt must precede the target start. The settled manifest must cover the exclusive target end, be observed after settlement, and be available by the requested evaluation cutoff. A qualified win carries its original value and occurrence and observation witnesses. No-win requires a source witness for continuous coverage. An unknown outcome or amount stays unknown. New entrants are outside this saved-cohort definition.

Periods use the same scope, original currency, outcome and settlement/restatement definitions, forecast version/model/scenario, calendar and timezone. The version 1 kernel rejects overlapping periods and repeated manifest IDs. It scores a nonempty period only when every forecast and actual contribution is known. Aggregate metrics cover those fully scored periods, with omitted counts and reasons explicit. Error is forecast minus actual. Mean bias and MAE are exact ratios in the original currency. Weighted absolute error uses total absolute period error divided by total absolute actual period value. That ratio is unavailable when its denominator is zero. Known zeros still contribute to signed and absolute error.

Probability eligibility is separate. A base-model comparison needs declared out-of-time training/freeze evidence, a saved probability and a settled label for every included observation, and examples of both labels. This is an input-shape gate. Sufficient sample size, independence of repeated deal observations, leakage-free trained artifacts, actual calibration, drift, uncertainty and fallback remain separate model evaluation work.

The future custody and authority adapter must verify immutable saved and settlement receipts, exact scope and incarnation membership, the authorized definition and model versions, positive and negative witness completeness, and current viewer access before constructing these manifests. It must choose the permitted original/restated actual version and reject data from later corrections outside that fence. Identifiers and timestamps in this kernel cannot prove any of those facts. Neither a native forecast writer and reader nor a settled actual collector is supplied here. Seven focused fixtures pass. No canonical migration, report route, model fitting, production data or acceptance is included.
