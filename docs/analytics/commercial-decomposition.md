# Private commercial change bridge

The comparison is the change in original-currency won deal value for two nonoverlapping observed-entry cohorts measured at the same elapsed age. It requires complete settled periods, the same selected scope, calendar/timezone, maturity horizon and frozen segment definition, and a known value for every observed first win. It reconciles independent period counts and values to the supplied cells. A source adapter still has to prove membership, unique first wins, frozen segment assignment and access at the selected cutoffs.

For each supported segment, value is entrant volume × share of entrants × win rate × mean value per win. Hold three factors fixed and replace one in this order: total volume, segment mix, conversion rate, then average won size. The four effects add up to the supported segments’ change exactly. Changing the order redistributes interactions between effects. If a segment is missing or has no wins in either period, its unobserved counterfactual size is not estimated; its net change remains in a separate unsupported component. All components including that residual reconcile to observed change. Signed rational values are exact in ten-thousandths of the selected currency’s major unit. No FX conversion or causal interpretation is performed.

The value identity follows the general [price-times-quantity accounting relationship](https://unstats.un.org/UNSD/mbs/ddform.aspx?getitem=50); the four-factor bridge and order are this report’s explicit convention. Seven focused cases cover the hand-calculated bridge, fractional effects, mix-only shift, zero baseline, missing segment support, inconsistent totals and inadmissible windows or definitions. No data source, route, historical production report or causal claims are supplied.
