# Code of Conduct

Warpdrive welcomes contributors with different backgrounds, languages and experience.
These expectations apply to repository issues, pull requests, reviews and discussions.

- Be respectful and patient. Critique the work with concrete reasons and useful examples.
- Make room for questions, language differences and newcomers.
- Respect privacy. Share only data and screenshots you have permission to publish.
- Do not harass, threaten, discriminate, make unwanted sexual remarks, reveal private
  information or repeatedly disrupt someone else's participation.
- Respect a maintainer's request to stop an interaction or move a discussion.

For routine moderation, contact [@KhademOHAli1](https://github.com/KhademOHAli1) with a
neutral request for follow-up. Do not publish private allegations or identifying evidence.
Use GitHub's **Report content** controls for abuse or threats. Security vulnerabilities
belong in the [private security reporting form](https://github.com/KhademOHAli1/warpdrive/security/advisories/new).

Maintainers may edit or remove content, close disruptive conversations, or restrict
participation according to the severity and persistence of the behavior. They should
apply these expectations consistently and explain moderation decisions when appropriate,
while protecting private information.
